# Restaurant-Management
This program checks bills placed by customer at restaurants and allow customers to order food through their bills online without manual recording and ordering.

Instead of paper based system, software will allow user to register his/her bill in his mobile phone, and when he use the bill, transactions will be recorded in the database, after each meal transaction report will be generated as pdf report. The report will contain QR code/code which will be verified using Meal/Restaurant administrator's software.This automation will
(i) Save time.
(ii) Replace paper based system
(iii) Accuracy
(iv) Report per each meal.

Software targets only restaurants and cafateria.
